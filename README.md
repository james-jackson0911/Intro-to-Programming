# CS-500 Introduction to Programming Portfolio

## Overview

This repository contains coursework completed for **CS-500: Introduction to Programming** at Southern New Hampshire University (SNHU). Throughout this course, I developed foundational programming skills using Python while learning software development practices such as problem solving, debugging, testing, code organization, and documentation.

The artifacts included in this repository demonstrate my growth from understanding basic programming concepts to developing a complete application as a final project. Each assignment reflects the application of programming principles, critical thinking, and software development best practices.

Through the completion of these assignments, I gained experience with:

### CS-500 Personal Budget App (Final Project)
**Topic:** Personal Finance Management Application

The Personal Budget App serves as the culminating project for CS-500. This Python application allows users to manage personal finances by tracking income and expenses while monitoring overall budget performance.

#### Key Features
- Add income entries
- Record expenses
- Calculate remaining budget
- Display financial summaries
- User-friendly menu system
- Input validation
- Organized and reusable functions

#### Technologies Used
- Python
- Visual Studio
- Command-Line Interface (CLI)

#### Programming Concepts Applied
- Variables and data types
- Functions
- Conditional statements
- Loops
- Lists and data management
- User input processing
- Modular programming
- Error handling and validation

**Skills Demonstrated:**
- Software design
- Application development
- Debugging and testing
- Code organization
- Problem solving
- Program documentation
